| C8 Productivity        | Q21  | Q29             | Q37   |

### Important note

The current questionnaire does not measure every criterion identically for every tool.

Before finalising the questionnaire, the researcher should decide whether the missing combinations should be added.

This is important because a completely symmetrical dataset makes the final comparison more statistically consistent.

# 13. Recommended Questionnaire Improvement

To make the comparison stronger, the questionnaire should ideally use the same core criteria for all three tools.

The recommended structure is:

| Criterion           | Jira | Teams | Slack |
| ------------------- | ---- | ----- | ----- |
| Communication       | ✓    | ✓     | ✓     |
| Task Management     | ✓    | ✓     | ✓     |
| Collaboration       | ✓    | ✓     | ✓     |
| Information Sharing | ✓    | ✓     | ✓     |
| Usability           | ✓    | ✓     | ✓     |
| Integration         | ✓    | ✓     | ✓     |
| Project Visibility  | ✓    | ✓     | ✓     |
| Productivity        | ✓    | ✓     | ✓     |

This would produce a cleaner comparison for Python analysis.

The questionnaire should therefore be reviewed before distribution.
