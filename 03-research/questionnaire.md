# Research Questionnaire

## Project Title

**Evaluating Collaboration Tools for Effective Virtual IT Project Management: A Comparative Study of Jira, Microsoft Teams and Slack**

---

# Participant Information

## Purpose of the Study

This questionnaire is part of an academic research project investigating the effectiveness of collaboration tools in virtual IT project management.

The study focuses on:

* Jira
* Microsoft Teams
* Slack

The research aims to understand how these tools support communication, task management, collaboration, information sharing and productivity in virtual or hybrid IT project environments.

Participation is voluntary.

Before distributing this questionnaire, the researcher will confirm the applicable university research-ethics and consent requirements.

# 3. Questionnaire Design Principles

The questionnaire has been designed to:

* Align questions with the research questions.
* Avoid unnecessary personal information.
* Use consistent rating scales.
* Collect both quantitative and qualitative information.
* Allow participants without experience of all three tools to participate.
* Support later statistical and thematic analysis.

* Bar charts
* Comparison charts

* Ranking charts

### Qualitative Analysis

# 6. Participant Data Protection

The questionnaire should not request unnecessary personally identifiable information.

The researcher should avoid collecting:

* Full names
* Personal addresses
* Passwords
* Private company information
* Confidential project information
* Sensitive personal information unless explicitly required and approved

Raw research data should be stored securely.

Raw participant data should **not** be uploaded to a public GitHub repository.

An anonymised dataset or synthetic dataset may be created for the public project repository if appropriate.

# 7. Pilot Testing

Before full distribution, the questionnaire should be piloted with a small number of suitable people.

The pilot should check:

* Question clarity
* Questionnaire length
* Technical functionality
* Response options
* Potentially confusing questions
* Missing response options
* Data-analysis compatibility

Feedback from the pilot should be documented.
