# Project Schedule

## Project Title

**Evaluating Collaboration Tools for Effective Virtual IT Project Management: A Comparative Study of Jira, Microsoft Teams and Slack**

## Project Duration

**12 Weeks**

## Scheduling Approach

The project will be completed over a 12-week period. Activities are organised according to project phases and dependencies. Some activities may overlap where appropriate.

The schedule will be reviewed weekly and updated when significant changes occur.

# 4. Schedule Monitoring

Project progress will be reviewed weekly.

The following indicators will be monitored:

* Planned tasks
* Completed tasks
* Delayed tasks
* Upcoming tasks
* Project milestones
* Risks affecting the schedule
* Changes to project scope
* Dependencies between activities

Any significant delay will be recorded and appropriate corrective action will be considered.

# 5. Schedule Change Control

Changes to the project schedule will be documented when they significantly affect project milestones, deliverables or the planned completion date.

Schedule changes will be reviewed against:

* Impact on project objectives
* Impact on project scope
* Impact on research quality
* Impact on resources
* Impact on final completion date
