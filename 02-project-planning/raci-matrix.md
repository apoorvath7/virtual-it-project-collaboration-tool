# RACI Matrix

## Project Title

**Evaluating Collaboration Tools for Effective Virtual IT Project Management: A Comparative Study of Jira, Microsoft Teams and Slack**

## 1. Purpose

The RACI Matrix defines project responsibilities and clarifies who is Responsible, Accountable, Consulted and Informed for key project activities.

The matrix will help avoid unclear responsibilities and ensure that important project activities have appropriate ownership.

## 2. RACI Definitions

| Code | Meaning     | Description                                   |
| ---- | ----------- | --------------------------------------------- |
| R    | Responsible | Person who performs the work                  |
| A    | Accountable | Person ultimately responsible for the outcome |
| C    | Consulted   | Person whose input or expertise is required   |
| I    | Informed    | Person who should receive updates             |

## 3. Stakeholder Roles

| RP   | Research Participants             |

# 5. Responsibility Principles

## Project Manager / Researcher

The Project Manager is responsible for the day-to-day management and delivery of the project.

Responsibilities include:

* Project planning
* Schedule management
* Risk management
* Research
* Data collection
* Data analysis
* Documentation
* Stakeholder communication
* Quality control
* Final reporting

## Academic Supervisor

The Academic Supervisor provides academic oversight and guidance.

Responsibilities include:

* Reviewing project direction
* Providing methodological guidance
* Reviewing major deliverables
* Providing feedback
* Supporting academic quality

## Research Participants

Research participants contribute primary research data through questionnaires and/or interviews.

Their participation is voluntary and subject to the appropriate information and consent requirements.

## IT Professionals

IT professionals may provide practical perspectives on virtual IT project management and collaboration tools.

## Software Developers

Software developers may contribute technical perspectives relating to collaboration, communication and project work.

## Business Analysts

Business analysts may provide perspectives on requirements, stakeholder communication and collaboration.

## University

The university provides the academic and research framework within which the project is conducted.

# 6. RACI Review

The RACI Matrix will be reviewed when:

* Project responsibilities change.
* New stakeholders become involved.
* Research activities change.
* Additional project team members are introduced.
* Major scope changes are approved.

Any significant responsibility changes will be documented and reflected in the project records.
